Why aren't we shipping faster now?

Notes on Christian Bird's talk Why aren't we shipping faster now? (YouTube). I recommend watching the video at 1.5x speed.

Basically the gist is that while coding agents have made code cheaper, all the other parts of releasing are now the significant bottlenecks.

Some interesting takeaways:

  • Human reviewers tend to be good at finding maintainability bugs, whereas agents are good at finding severe and reliability bugs. (Reliability bugs here meaning something like "the system performs worse with more load")
  • We need to improve the code review process (which Bird says hasn't fundamentally changed since the 70s) to help with the code review bottleneck.
